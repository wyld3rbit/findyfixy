# Day 8. One path to every model

**Outcome:** the third transition of `code/docs/strategy.md`. Every model call, from the app and from the harness, goes through one gateway that enforces a budget, the routing rule and the model pins. The invariant "no model call bypasses the gateway" moves from planned to built, with a test that fails on any model client outside it. Cost per run is then cut lever by lever, each change measured against the baseline, with the quality gate still passing.

## Concept (25 min)

**Why one path.** Today model clients are created in several app and harness modules (the strategy's diagnosis has the count). A budget, a route or a model pin enforced in one of them is bypassed by the others. A gateway turns those rules into one checkpoint: it holds the provider keys so callers never do, enforces budgets and rate limits per key, logs spend centrally, routes by model alias and fails over between providers. Model choice becomes configuration instead of code.

**Where the cost and the time go.** Inference has two phases. Prefill processes every input token in parallel and builds the key-value (KV) cache, the model's working memory for the prompt; its cost scales with input length and it sets time to first token. Decode then generates output one token at a time, each step reading the whole KV cache, so it dominates wall-clock time for long answers. Hosted providers price the two phases separately, with output tokens costing several times more than input.

**Cost is a design property.** It is set by routing, context size, caching and output length, all decided in the architecture. The levers, in order of typical impact:

1. **Routing.** The share of runs that reach the large model. With escalation now computed (Day 7), the threshold is a measured lever.
2. **Context budget.** Every retrieved chunk and tool schema is paid in prefill on every call.
3. **Prefix caching.** When requests share an identical prefix, the runtime reuses the stored KV cache. It only works when the stable parts (system prompt, schema, tool definitions) come first and the variable parts last; one changed byte early in the prompt invalidates everything after it.
4. **Response caching.** Identical requests answered from a cache. Semantic caching matches near-identical ones by embedding similarity, saves more, and risks a stale or wrong answer, so it needs a tight threshold and an expiry.
5. **Output length.** Cap output at what the schema needs; decode is the slow phase.

**Judging a lever.** A lever is kept only when its cost change is measured against the baseline and the quality gate still passes. The reference price table from Day 6 makes local and hosted cost comparable.

## Build

Blueprint first: the LiteLLM proxy (MIT, open-source tier), run as a container pinned by digest and scanned with Grype before first use. Never versions 1.82.7 or 1.82.8, which were compromised on PyPI in March 2026. The harness gains a model port; the gateway is its implementation.

### 1. Baseline

From the traces, record per golden run: tokens in, tokens out, latency, escalation rate and reference cost. These are the numbers every lever is measured against.

### 2. The gateway

`code/infra/` gains the proxy's compose file, bound to 127.0.0.1, with three aliases pointing at Ollama: small, large and the judge. Every model client in the app and the harness moves behind the model port. An architecture test fails if any module other than the gateway adapter imports a model client. The gateway's config, in the code tree, pins each alias to the full digest from `ollama list`, so a silent model swap fails a run instead of changing answers. `record/models.md` gains the judge's full digest, which it lacks today.

### 3. Budget

A virtual key with a budget. Pushing runs past it is refused, and the refusal is a trace event.

### 4. Pull the levers

One change at a time, each re-run on the golden set, each recorded as a change against the baseline in cost, latency and every gate measure:

1. The escalation threshold on the computed signal (three settings, set before the runs).
2. A context cap on recalled incidents.
3. Prompt order for prefix caching: stable parts first.
4. An output cap at what the schema needs.

### 5. Optional: hosted comparison

With an API key for a hosted model, add it as a fourth alias and route escalations there for one golden run. Compare cost, latency and quality against the local large model. The course works without it.

### 6. Visualizer and artifacts

The Gateway box turns built. ADR 0009 records the phase and reports against the strategy. The strategy's gateway row moves to built, and its second gap closes. READMEs, CHANGELOG, tracker and ADR snapshot updated in the same commits.
