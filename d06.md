# Day 6. Observability

**Outcome:** every run traced in Langfuse with tokens, cost, latency and model per step; eval scores attached to traces; three questions you can answer from the dashboard.

## Concept (20 min)

- **An agent you cannot trace, you cannot operate.** A trace is the tree of one run: graph node, LLM call, tool call, retrieval. Each span carries inputs, outputs, tokens, cost and duration.
- **What leaders read from traces.** Cost per resolved incident. Escalation rate to the large model. p95 latency by node. Where failures cluster.
- **OpenTelemetry GenAI semantic conventions** standardise span attributes such as `gen_ai.request.model`, `gen_ai.usage.input_tokens` and `gen_ai.usage.output_tokens`. Langfuse accepts OTel, so traces stay portable across vendors.
- **Scores on traces.** Attach eval scores and user feedback to the trace. Quality and cost then sit side by side.

## Lab (90 min)

### 1. Run Langfuse locally

Langfuse runs Postgres, ClickHouse, Redis and MinIO as containers. On a 16 GB Mac, give the container runtime 8 GB for this (Colima: `colima stop && colima start --memory 8`; Docker app: Settings, Resources), close other heavy apps, and stop Langfuse when not in use.

Ask Claude Code to put Langfuse's official compose file in `code/infra/langfuse/`, taken from the latest release tag of the Langfuse repo, with image tags pinned and its own secrets in `code/infra/langfuse/.env`. Then:

```bash
docker compose -f infra/langfuse/docker-compose.yml up -d
# open http://localhost:3000, create a project, copy the keys into code/.env
```

It lives inside the repo but runs as its own stack. Stop it with `docker compose -f infra/langfuse/docker-compose.yml down`.

Add these to `.env`: `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, `LANGFUSE_HOST=http://localhost:3000`.

### 2. Instrument

```bash
uv add langfuse
```

Pass the Langfuse LangChain `CallbackHandler` in the graph's `config={"callbacks": [handler]}`. Wrap retrieval and ingestion in `@observe()` so they show as spans. Tag each trace with `model_used` and `escalated`.

### 3. Attach eval scores

Change `eval_answers.py` so each golden case writes its RAGAS scores to its trace with the Langfuse score API.

### 4. Answer from the dashboard

Run the golden set twice. Then answer in `notes/day6.md`:

1. Average cost per run, local only vs escalated.
2. The slowest node at p95.
3. The 3 lowest-faithfulness traces, and what retrieval returned for each.
