# Notes

Run records for the build, written from runs that were done: `notes/day1.md` to `notes/day4.md` for each day's setup, results and findings, `notes/evidence.md` for one verified sentence per day, `notes/models.md` for the model IDs recorded after each pull so a silent swap is visible, and `notes/plans/` for approved plans such as `notes/plans/day5-eval-harness.md`.

A number quoted elsewhere in the repository traces to a file here or to a saved report. Reports from the evaluation runs are written to `code/reports/`, which is git-ignored because they are regenerated.
