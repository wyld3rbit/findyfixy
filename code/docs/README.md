# Docs

`code/docs/architecture.html` is the interactive architecture page. It shows the graph as built and the steps still planned, and it follows a live run from the console's event stream. Start the console with `make console`, or run `make ui` for the tracker and the console together.

`code/docs/adr/` holds one architecture decision record per phase, each with a diagram drawn from the architecture page by `make adr-snapshot`.

`code/docs/demo.gif` and `code/docs/space-needle.png` are the images used by the top-level README.
