# Data

Synthetic data only. Nothing here comes from a real incident, customer or employer.

- `code/examples/findyfixy/data/incidents.jsonl` is the incident corpus, generated by `code/examples/findyfixy/src/findyfixy/retrieval/corpus.py`.
- `code/examples/findyfixy/data/incidents.json` is a small hand-written bank of incident excerpts with answer keys, used by the Day 2 measurements.
- `code/examples/findyfixy/data/deploys.json` is the fake deploy history the deploy tool reads.
- `code/examples/findyfixy/data/golden.jsonl` holds the holdout cases that score the agent.
- `code/examples/findyfixy/data/retrieval_eval.jsonl` holds the labelled queries that score retrieval.
